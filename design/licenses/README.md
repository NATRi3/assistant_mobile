# Источники и лицензии

Оригинальные SVG/HTML/CSS/JS, синтетический контент и токены созданы для этого
workspace. Заимствованных изображений, шрифтов, icon pack и runtime-зависимостей нет.
Стрелки и статусные символы — обычные текстовые glyphs системного шрифта.
Шрифт не распространяется в комплекте; наличие кириллицы проверяет браузер/Android QA.

Применены установленные навыки `mobile-android-design`, `design-system-patterns`,
`visual-design-foundations`, `interaction-design`, upstream `wshobson/agents`, MIT,
commit `7e2fb559cf4b824b27f1fec49fe88f7511066d26`; инструкции не переписаны.
`upstream-skills-MIT.txt` — настоящая копия upstream LICENSE; provenance и хеши
навыков — [skills-provenance.json](skills-provenance.json), копия проверенного
installation manifest; исходные пути в нём описывают локальную установку навыков,
а не обязательные ресурсы для просмотра макетов.
Ни один пример Kotlin/React из навыков не скопирован в продуктовый runtime.
